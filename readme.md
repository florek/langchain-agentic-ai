# LangChain Agentic AI

Repozytorium szkoleniowe tworzone podczas przerabiania kursu **Agentic AI Engineering with LangChain and LangGraph**.

Celem projektu jest praktyczne poznanie budowania aplikacji LLM, agentów AI oraz systemów agentowych z użyciem **LangChain**, **LangGraph** i powiązanych narzędzi ekosystemu GenAI.

## Zakres nauki

Repozytorium obejmuje ćwiczenia i notatki związane z projektowaniem oraz implementacją nowoczesnych aplikacji opartych o modele językowe, w tym:

* podstawy Agentic AI,
* budowanie agentów AI,
* architektury agentowe,
* systemy multi-agentowe,
* LangChain,
* LangGraph,
* prompt engineering,
* context engineering,
* ReAct prompting,
* few-shot prompting,
* tool calling,
* RAG,
* vector databases,
* memory systems,
* LangSmith tracing,
* Model Context Protocol,
* deep agents.

## Cel repozytorium

To repozytorium nie jest gotowym produktem ani biblioteką do użycia wprost.
Jest miejscem do utrwalania wiedzy, eksperymentowania i budowania praktycznych umiejętności związanych z tworzeniem aplikacji GenAI.

Najważniejsze cele:

1. Zrozumieć, jak działają aplikacje LLM pod spodem.
2. Nauczyć się budować agentów korzystających z narzędzi.
3. Poznać różnice między klasycznym podejściem LLM, RAG i agentami.
4. Przećwiczyć LangChain i LangGraph na praktycznych przykładach.
5. Utrwalać wiedzę w kodzie, dokumentacji i quizach.
