# Klucz odpowiedzi – 23.09.2026

Skład: pytania 1–10 = ostatnia lekcja (PromptTemplate, LCEL, modele chat); 11–20 = wcześniejsze notatki (wprowadzenie do Agentic AI).

| Pytanie | Poprawna | Krótkie uzasadnienie |
|---------|----------|----------------------|
| 1 | C | `load_dotenv()` ładuje zmienne środowiskowe (np. klucz API) do procesu przed utworzeniem klienta. |
| 2 | A | `PromptTemplate` buduje się z `template` (placeholdery) oraz `input_variables`. |
| 3 | D | Operator `\|` w LCEL składa szablon z modelem w łańcuch Runnable. |
| 4 | B | `temperature=0` dąży do bardziej deterministycznych, powtarzalnych odpowiedzi. |
| 5 | A | Tekst generacji modelu chat odczytuje się typowo przez `.content`. |
| 6 | C | `invoke` przyjmuje słownik kluczy zgodnych z `input_variables` szablonu. |
| 7 | D | `ChatOpenAI` korzysta z API w chmurze, `ChatOllama` z lokalnego serwera Ollama. |
| 8 | B | Szablon jest Runnable — da się go złożyć w łańcuch i wielokrotnie wywoływać z różnymi danymi. |
| 9 | C | Bez załadowanych zmiennych wywołanie `ChatOpenAI` kończy się błędem braku klucza / autoryzacji. |
| 10 | A | Przy zmianie backendu zostaje ten sam wzorzec: szablon, `prompt \| llm`, `invoke` ze słownikiem. |
| 11 | B | Klasyczny LLM to prompt→model; RAG dodaje wyszukiwanie wiedzy; agent decyduje, używa narzędzi i kontekstu. |
| 12 | D | Agentic AI: model decyduje o krokach, może używać narzędzi i utrzymywać kontekst. |
| 13 | A | LangChain składa aplikacje LLM; LangGraph buduje przepływy agentowe (grafy, pętle). |
| 14 | C | Context engineering zarządza tym, co trafia do kontekstu modelu (dokumenty, historia, narzędzia, limity). |
| 15 | D | Few-shot to przykłady w prompcie pokazujące oczekiwany format lub styl. |
| 16 | A | RAG dostarcza wiedzę z dokumentów; agent dodatkowo steruje przebiegiem i narzędziami. |
| 17 | B | LangSmith służy do tracingu i obserwowalności przebiegów LLM. |
| 18 | D | ReAct to wzorzec thought / action / observation przy agentach z narzędziami. |
| 19 | C | Wcześniejsza znajomość ML nie jest wymagana — wystarczy m.in. Python, Git, venv, env vars. |
| 20 | A | Pułapka: traktowanie każdego wywołania LLM jako agenta bez narzędzi, pętli decyzji i pamięci. |
